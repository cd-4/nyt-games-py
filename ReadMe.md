# NYT Games Cli

Press [1-6] to switch games

## Install and run

```console
python -m pip install .
nyt-games-cli
```

For development, use `python -m pip install -e .`. You can also run the app as
`python -m nyt_games_cli`. The app must be run in an interactive terminal.

Controls:

1. Wordle
2. Connections
3. Strands
4. Mini Crossword
5. Letter Boxed
6. Spelling Bee
